# C++ Maths for DSA

This repository contains my C++ practice programs focused on mathematical concepts and problem-solving techniques used in Data Structures and Algorithms (DSA).

I'm building a strong foundation in mathematics and number-based problems to improve my logical thinking and coding skills for technical interviews.

## 📚 Topics Covered

- **Prime Number:** Checking whether a number is prime.
- **Sieve of Eratosthenes:** Finding prime numbers efficiently.
- **Count Digits:** Counting the total number of digits in a number.
- **Sum of Digits:** Calculating the sum of individual digits.
- **Divisibility:** Practicing basic mathematical operations.
- **Number-Based Problems:** Implementing mathematical logic using loops and functions.

## 🛠️ Technologies Used

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-link>
```

2. Open the project folder.

3. Compile a C++ file:

```bash
g++ test.cpp -o test
```

4. Run the program:

```bash
./test
```

**Note:** On Windows PowerShell, use `.\test.exe` to run the compiled program.
